---
description: 压缩当前上下文：生成会话摘要，自动新建对话并粘贴到输入框
---

用户请求压缩当前对话的上下文。按以下步骤执行：

1. 用 Bash 运行：
   ```
   curl -s -m 15 "http://127.0.0.1:9335/smartcompact"
   ```
   返回 `{"ok":true,"summaryLength":N}` 表示摘要已生成、写入剪贴板、并自动粘贴到了新建对话的输入框。

2. 用 Bash 读取摘要全文（供你在回复中展示给用户确认）：
   ```
   powershell -NoProfile -Command "Get-Clipboard"
   ```

3. 把剪贴板里的摘要文本**完整输出到你的回复中**（放在代码块里），让用户能看到摘要内容。

4. 告知用户：
   - 摘要已自动粘贴到**新建对话**的输入框里
   - 请**切换到新对话标签**确认内容后按回车发送
   - 发送后旧对话就可以关掉了

5. 如果第 1 步返回 `{"ok":false}` 或 curl 失败：
   - 说明 Token Bar 的 9335 服务没有在跑（app.asar 补丁版没装或 ZCode 刚重启还没就绪）
   - 改用备用方案：直接根据你（agent）对当前对话的记忆，写一份上下文摘要放在代码块里，让用户复制到新对话
