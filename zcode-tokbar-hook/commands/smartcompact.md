description: 压缩当前上下文：生成会话摘要，新建对话并粘贴到输入框
---

用户请求压缩上下文。调用 Token Bar 的本地服务生成摘要并自动粘贴到新对话：

1. 用 Bash 运行：
   `curl -s -m 15 "http://127.0.0.1:9335/smartcompact"`
2. 确认返回 `{"ok":true,...}`。
3. 摘要已自动粘贴到新对话的输入框里。告知用户"摘要已填入新对话输入框，请确认内容后按回车发送"，不要读图或重复摘要内容。
4. 如果返回 `{"ok":false}` 或 curl 失败，告知用户 Token Bar 的 9335 服务没有在跑（需要 app.asar 补丁版）。
